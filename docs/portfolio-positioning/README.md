## How to use this pack

- Text labelled **Public copy** can be transferred into the design. Confirm client naming and permission to use identities before publication.
- Text labelled **Editorial / implementation notes** guides the build and evidence collection; it is not visitor-facing content.
- The case-study narratives intentionally avoid unverified metrics, testimonials, and revenue attribution. The outlines are complete; supporting evidence can be added without changing their structure.
- The management scope is a recommended default offer for future engagements. It does not change existing client agreements. Fees are quoted against scope and volume.
- The existing application, its uncommitted changes, and production have not been modified by this content work.

## Evidence boundary

The client project list and delivery experience come from Sandesh's description. Earlier project notes inform possible case-study angles, not current production guarantees. The public site and local draft were reviewed in the preceding research phase.

Do not carry the local draft's 500+ conversations, 30+ visits, five villa sales, one-week window, or under-three-second claims into the new site without evidence. Sandesh's reported under-two-second performance also needs a defined measurement before publication. Use neutral capability wording in the meantime.

The local draft associates Yutha with Vijayawada, while the public project page identifies Tranquil Meadows in Anantapur. Establish which location a case study refers to before adding it. Use the client-approved spelling of Sharada/Sharadha and Tungabhadra Developers.
